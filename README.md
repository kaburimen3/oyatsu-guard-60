# おやつ防衛隊！

カメラで手のジェスチャーを読み取り、防衛アイテムを配置して、迫ってくるちびっこたちからおやつを守る60秒のやさしいタワーディフェンスゲームです。

ちびっこを攻撃するゲームではありません。配置したアイテムに触れたちびっこは「ありがとう」「ねんね」などの吹き出しを出し、笑顔で画面の外へ帰っていきます。キャラクターには親しみやすいイラスト素材を使用しています。

## Demo

[ゲームをプレイする](https://oyatsu-guard-60.kaburimen.chatgpt.site)

## 操作方法

### カメラで遊ぶ

1. 手を動かし、防衛アイテムを置きたい場所に合わせます。
2. 指をつまむジェスチャーをすると、その場所に防衛アイテムを配置します。
3. ちびっこが配置したアイテムに触れると、吹き出しでひとこと話して画面端へ帰ります。

手が映っているだけではアイテムは配置されません。置きたい場所でジェスチャーしてください。

### マウス・キーボードで遊ぶ

- マウス移動：配置する場所を選ぶ
- クリック：カーソル位置に防衛アイテムを配置
- Spaceキー：現在のカーソル位置に防衛アイテムを配置

カメラ映像はブラウザ内のジェスチャー認識にだけ使用し、アプリ側では保存・送信しません。

## ゲーム内容

- 制限時間：60秒
- 守るおやつ：5個
- 防衛アイテムを好きな場所に配置するタワーディフェンス
- ちびっこは攻撃されず、吹き出しを出して画面端へ帰る安心設計
- ドット絵ではなく、親しみやすいイラストのキャラクター
- スコア、コンボ、ベストスコア
- PC・スマートフォン対応

## ローカル起動

必要環境：Node.js 22.13.0以上

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。カメラを利用する場合は、ブラウザのカメラ権限を許可してください。
