# おやつ防衛隊！

カメラで手のジェスチャーを読み取り、迫ってくるちびっこたちからおやつを守る、60秒のやさしいタワーディフェンスゲームです。

子どもたちは倒れたり傷ついたりしません。ガードやバリアに触れると、笑顔で画面の外へ帰っていきます。

## Demo

[ゲームをプレイする](https://oyatsu-guard-60.kaburimen.chatgpt.site)

## 操作方法

- 手を動かす：ガードを移動
- 親指と人差し指をつまむ：範囲バリアを発動
- マウス移動：カメラが使えない場合のガード操作
- クリックまたはスペースキー：範囲バリアを発動

カメラ映像はブラウザ内のジェスチャー認識にだけ使用し、アプリ側では保存・送信しません。

## ゲーム内容

- 制限時間：60秒
- 守るおやつ：5個
- 接触ガード、範囲バリア、コンボ、ベストスコア
- PC・スマートフォン対応
- オリジナルのピクセルアート描画

## ローカル起動

必要環境：Node.js 22.13.0以上

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。カメラを利用する場合は、ブラウザのカメラ権限を許可してください。

## 確認
