# おやつ防衛隊！

カメラで手のジェスチャーを読み取り、おもちゃを配置して、迫ってくるちびっこたちからおやつを守る60秒のやさしいタワーディフェンスゲームです。

ちびっこを攻撃するゲームではありません。配置したおもちゃに触れた子は「ありがとう」「ねんね」などの吹き出しを出し、笑顔で画面の外へ帰ります。

## Demo

[ゲームをプレイする](https://oyatsu-guard-60.kaburimen.chatgpt.site)

## 操作方法

### カメラ

- 指をつまむ：通常のおもちゃを配置（耐久1・最大5個）
- Vサイン：強いおもちゃを配置（耐久3・最大3個）
- 手を動かす：半透明のプレビューで配置場所を選択（最寄りのレーンへ自動吸着）

手が映っているだけでは配置されません。置きたい場所でジェスチャーしてください。

### マウス・キーボード

- クリック／Space：通常のおもちゃを配置
- Shift＋クリック／Sキー：強いおもちゃを配置

### スマートフォン

- 画面下の「くま」「つよいロボ」でおもちゃを選択
- ゲーム画面をタップして、光っているレーンへ配置

カメラ映像はブラウザ内のジェスチャー認識だけに使用し、アプリ側では保存・送信しません。

## ゲーム内容

- 制限時間60秒、おやつ5個
- 通常・強化の2種類のおもちゃを配置
- 強いおもちゃは3回接触するまで残り、盤面に最大3個
- 配置前のおもちゃプレビューと5レーンへの自動吸着
- 絵本風の子ども、おやつ、保育園背景
- 帰るときの吹き出し、コンボ、ベストスコア
- PC・スマートフォン対応

## ローカル起動

Node.js 22.13.0以上が必要です。

```bash
npm install
npm run dev
```
